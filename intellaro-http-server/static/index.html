Features

Everything you need in an HTTP server

Production-grade capabilities with zero-downtime config reloads and a built-in management API.

⇄

Reverse Proxy

Transparent HTTP/1.1 and HTTP/2 proxying with automatic host header forwarding, path preservation, and connection pooling.

⚖

Load Balancing

Round-robin, weighted, least-connections, and sticky-session strategies with active health checking and automatic failover.

⚡

Response Caching

In-memory response cache with configurable TTL, max entries, and optional POST caching. Serves cached responses in microseconds.

⚠

Security

Per-client rate limiting with sliding windows, IP allow/block lists (CIDR), JWT validation, and path traversal protection.

▣

Prometheus Metrics

Request counts, response codes, latency histograms, cache hit ratios, and active connections — all on a /metrics endpoint.

↻

Hot Reload

File-watch based config reload with zero downtime. Also supports runtime updates via the management API with API-key auth.

Configuration

Simple YAML, powerful defaults

A minimal config is all you need. Every field has a sensible default.

config.yaml 
listeners:
  - address: "0.0.0.0:8080"
    protocol: auto

upstreams:
  - name: default
    servers:
      - address: "backend-1:80"
      - address: "backend-2:80"
    load_balancing: round_robin
    health_check:
      path: /healthz
      interval_secs: 10

cache:
  enabled: true
  max_entries: 10000
  default_ttl_secs: 300

security:
  rate_limit:
    max_requests: 500     # per client
    window_secs: 60

logging:
  level: info
  format: json
  metrics_path: /metrics

management_api:
  address: "0.0.0.0:9091"
